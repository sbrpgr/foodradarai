## 🎯 프로젝트 개요

FoodRadar.AI는 72조 원 규모의 국내 가공식품 시장에서 소비자의 합리적 의사결정을 돕는 AI 기반 식품 분석 플랫폼입니다.

### 해결하고자 하는 문제
- **정보 해독의 한계**: 복잡한 원재료명과 영양정보 해석의 어려움
- **정보 탐색의 비효율**: 여러 플랫폼을 오가는 번거로운 제품 비교 과정
- **신뢰할 수 있는 정보의 부재**: 광고와 주관적 후기에 의존하는 현실

### 제공하는 솔루션
- **AI 기반 3초 유사 제품 탐색**: 의미적 유사성을 고려한 지능형 제품 탐색
- **6대 핵심 지표 동시 비교**: 가격효율성, 영양균형, 유해성분, 첨가물안전성, 소비자신뢰도, 친환경성
- **공공데이터 기반 객관적 분석**: 식품의약품안전처 데이터 활용한 신뢰성 있는 분석
- **실시간 최저가 정보**: 주요 이커머스 플랫폼의 가격 비교 및 구매 링크 제공

## ✨ 핵심 기능

### 🤖 **실제 AI 분석 엔진**
- **Google Gemini 1.5 Flash**: 실시간 제품 분석 및 비교
- **Gemini Vision API**: 제품 이미지 자동 인식 및 분석

### 🔍 다중 입력 방식 지원
- **텍스트 입력**: 제품명 직접 입력 (예: "신라면 더레드")

- **원클릭 구매**: 최저가 판매처로 바로 연결되는 구매 링크

## 🗃 데이터 모델

### 1. Products Table (제품 정보)
```javascript
{
  id: "prod_001",                    // 제품 고유 ID
  name: "신라면 더레드",              // 제품명
  brand: "농심",                     // 브랜드명
  category: "instant-noodles",       // 카테고리
  price: 1200,                       // 기준가격(원)
  image_url: "https://...",          // 제품 이미지 URL
  ingredients: "면(밀가루...)",       // 원재료명
  nutrition_info: "{...}",           // 영양성분 정보(JSON)
  score_price: 75,                   // 가격효율성 점수(0-100)
  score_nutrition: 70,               // 영양균형 점수(0-100)
  score_harmful: 65,                 // 유해성분 점수(0-100)
  score_additives: 60,               // 첨가물안전성 점수(0-100)
  score_trust: 85,                   // 소비자신뢰도 점수(0-100)
  score_eco: 50,                     // 친환경성 점수(0-100)
  allergens: ["밀", "대두"],          // 알레르기 유발성분
  certifications: [],                // 인증정보 (유기농, 비건 등)
  keywords: ["매운맛", "라면"],       // 검색용 키워드
  status: "active"                   // 제품 상태
}
```


## 📡 API 엔드포인트

### Products API
- `GET /tables/products` - 제품 목록 조회 (페이징, 검색, 정렬 지원)
- `GET /tables/products/{id}` - 특정 제품 상세 정보
- `POST /tables/products` - 새 제품 등록
- `PUT /tables/products/{id}` - 제품 정보 전체 업데이트
- `PATCH /tables/products/{id}` - 제품 정보 부분 업데이트
- `DELETE /tables/products/{id}` - 제품 삭제 (소프트 삭제)

### Price Tracking API
- `GET /tables/price_tracking` - 가격 정보 목록 조회
- `GET /tables/price_tracking/{id}` - 특정 가격 정보 조회
- `POST /tables/price_tracking` - 새 가격 정보 등록
- `PUT /tables/price_tracking/{id}` - 가격 정보 업데이트

### Analysis History API
- `GET /tables/analysis_history` - 분석 이력 조회
- `POST /tables/analysis_history` - 새 분석 결과 저장

### 샘플 API 요청
```javascript
// 제품 검색
GET /tables/products?search=신라면&limit=10&page=1

// 제품별 가격 조회 (클라이언트 측 필터링)
GET /tables/price_tracking?limit=50

// 분석 결과 저장
POST /tables/analysis_history
{
  "query_text": "신라면 더레드",
  "query_type": "text",
  "base_product_id": "prod_001",
  "similar_products": ["prod_002", "prod_003"],
  "ai_summary": "...",
  "recommended_product_id": "prod_002"
}
```

## 📖 사용법

### 1. 🤖 **실제 AI 분석 시작하기**
1. 웹사이트 접속 시 **Gemini AI가 자동으로 연동됨** ✅
2. 메인 페이지에서 원하는 입력 방식 선택:
   - **텍스트**: 제품명 직접 입력 (예: "신라면 더레드")
   - **이미지**: 제품 사진 업로드 → **실제 AI 인식** 🔍
   - **링크**: 온라인 쇼핑몰 제품 URL 입력
   - **카테고리**: 원하는 제품 유형 선택

3. 분석 버튼 클릭 후 **실시간 AI 분석** (3-8초)

### 2. 📊 **3단계 상세 분석 결과**
1. **📈 제품 비교 탭**
   - 6대 핵심 지표 레이더 차트
   - AI 생성 요약 및 추천
   - 상세 비교표 및 최저가 정보

2. **🧪 원재료 분석 탭**  
   - **AI 기반 성분별 상세 분석**
   - 안전성 등급 및 기능 설명
   - 알레르기 정보 및 건강 주의사항
   - AI 종합 의견

3. **🍎 영양성분 탭**
   - 주요 영양성분 비교 차트
   - 영양적 장점 및 주의사항
   - 개인별 섭취 가이드

### 3. 💡 **AI 인사이트 활용**
- **실시간 AI 요약**: 복잡한 분석을 쉬운 언어로 설명
- **개인화 추천**: 사용자 기준에 맞는 최적 제품 제안
- **구매 가이드**: "왜 이 제품이 좋은지" 명확한 근거 제시

### 4. 🛒 **스마트 구매 결정**
- 각 제품별 "최저가 구매" 버튼 클릭
- 해당 제품의 최저가 판매처로 자동 연결
- AI 추천 근거를 바탕으로 확신 있는 구매

### 5. 📊 **API 사용량 관리**
- 우하단 사용량 위젯에서 실시간 모니터링
- 일일 한도 도달 시 자동으로 모의 분석으로 전환
- 투명한 사용량 표시로 안심 사용
