# FoodRadar.AI 데이터 폴더

## 📊 데이터 정보

이 폴더는 FoodRadar.AI 프로젝트의 데이터 저장소입니다.

### 🗃 원본 공공데이터
- **파일명**: 상품정보_가공식품(14,251).xlsx
- **크기**: 12.8MB  
- **상태**: 배포 최적화를 위해 임시 제거됨
- **설명**: 식품의약품안전처 공공데이터포털의 가공식품 정보 14,251개 제품

### 💡 데이터 활용 방법
실제 서비스에서는:
1. RESTful Table API를 통해 데이터베이스에서 제품 정보 조회
2. 샘플 데이터 6개 제품으로 시연 가능
3. 필요시 공공데이터를 별도 서버에 업로드하여 활용

### 🔄 데이터 복원
큰 데이터 파일이 필요한 경우:
- 공공데이터포털에서 재다운로드
- 별도 클라우드 스토리지 활용
- 서버 측 데이터베이스로 이전

---
**참고**: 현재는 배포 최적화를 위해 핵심 JavaScript 코드와 샘플 데이터만 포함되어 있습니다.
